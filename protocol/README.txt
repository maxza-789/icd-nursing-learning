NEONATAL ICD NURSING PROTOCOL — LANDING PAGE
================================================

ไฟล์เว็บไซต์: index.html
ภาพประกอบ: assets/
วิธีเปิดดู: ดับเบิลคลิก index.html หรือเปิดผ่านเว็บเบราว์เซอร์

วิธีเผยแพร่:
1) อัปโหลดโฟลเดอร์นี้ไปยัง GitHub repository หรือบริการ static hosting
2) เปิดใช้งาน GitHub Pages / Netlify / Vercel
3) เมื่อได้ URL สาธารณะ ให้สร้าง QR Code จาก URL นั้น
   (QR Code ที่ใช้งานได้ต้องชี้ไปยัง URL ที่เข้าถึงได้จากอินเทอร์เน็ต)

หมายเหตุ:
- ข้อความในหน้าเว็บนำมาจาก DOCX ต้นฉบับและจัดกลุ่มเพื่อให้อ่านง่าย
- ภาพประกอบทั้งหมดที่พบในไฟล์ Word ถูกคัดลอกไว้ใน assets/
- แผนภาพลำดับเนื้อหาเป็น visual navigation ของหัวข้อที่มีอยู่ในเอกสาร
- เว็บไซต์นี้ไม่แก้ไขหรือรับรองเนื้อหาทางคลินิก
